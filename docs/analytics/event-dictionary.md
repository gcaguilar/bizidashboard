# Diccionario de eventos

Fuente: `ANALYTICS_EVENT_CATALOG` en [`src/lib/analytics/events.ts`](../../src/lib/analytics/events.ts). Este documento se deriva de esa constante; si cambia el catálogo, actualiza esta tabla en el mismo cambio.

Hay **45 eventos**. Todos los nombres son `snake_case` estables, pertenecen a una de las siete categorías (`discovery`, `navigation`, `exploration`, `content`, `actions`, `workflows`, `quality`) y apuntan a uno de los seis dashboards (`product_overview`, `search_discovery`, `feature_adoption`, `navigation_engagement`, `ux_friction`, `conversion_workflows`).

> La clasificación de privacidad de todo el catálogo es `anonymous_aggregate`: datos agregados y seudónimos, nunca una identidad de persona. Los identificadores `distinct_id`/`$device_id` del SDK son seudónimos generados por PostHog, no datos personales recogidos por Bizi (ver [privacy-audit.md](./privacy-audit.md)).

## Vocabulario de propiedades

| Propiedad | Tipo | Valores / regla |
|---|---|---|
| `surface` | enum | `public`, `dashboard` |
| `route_key` | identificador | Clave estable de ruta (`home`, `explore`, `dashboard_alerts`, `monthly_report`…). Nunca la ruta cruda ni parámetros. |
| `page_type`, `template`, `module`, `source`, `destination`, `section`, `feature`, `action`, `operation`, `panel`, `tab`, `sort_key`, `view_mode`, `filter_category`, `filter_action`, `workflow_name`, `step_name`, `search_type` | identificador | Token corto en `snake_case` (o `camelCase` en `operation`). Sin espacios, URLs, `@`, `?`, `&` ni IDs. |
| `mode` | enum | `overview`, `operations`, `research`, `data` |
| `entity_type` | enum | `station`, `district`, `report`, `api`, `help` |
| `query_present` / `has_results` / `month_present` / `is_external` | booleano | `true` / `false` |
| `query_length_bucket` | enum | `0`, `1_2`, `3_5`, `6_plus` |
| `result_count_bucket` | enum | `0`, `1`, `2_5`, `6_20`, `21_plus` |
| `results_count` | número | Entero 0…1.000.000. Solo cuando el recuento exacto no es sensible. |
| `step_number` | número | Entero 1…1000. |
| `source_role` / `destination_role` | enum | `home`, `entry_seo`, `hub`, `detail`, `dashboard`, `utility` |
| `transition_kind` | identificador | p. ej. `to_dashboard`. |
| `export_format` | enum | `pdf`, `csv`, `json`, `png` |
| `result` | enum | `success`, `fallback`, `error`, `cancel`, `abandon`, `unavailable`, `empty` |
| `error_category` | enum | `network`, `render`, `validation`, `permission`, `unknown` |
| `error_code` | identificador | Código interno corto, p. ej. `NET_1`, `E500`. Nunca el mensaje de error. |
| `channel` | enum | `web_share`, `whatsapp`, `link` |
| `rating` | enum | `positive`, `negative` |

`sanitizeAnalyticsPayload` aplica estas listas: los valores enuméricos deben pertenecer al conjunto y el resto de cadenas deben ser tokens cortos sin texto libre. Por eso un valor como `'Alice Example'` o `'alice@example.com'` se descarta incluso si la clave está permitida.

## Eventos heredados

`LegacyAnalyticsInteractionName` (`api_cta_click`, `related_module_click`, `report_open_click`, `station_card_click`, `app_external_click`, `dataset_source_click`, `dataset_download_click`, `ad_landing_primary_click`, `ad_landing_secondary_click`, `home_cta_primary_click`) no son nombres de evento nuevos: `buildLegacyInteractionEvent` los traduce a `cta_click`, `navigation_click`, `entity_select` o `export_click` del catálogo. No los uses al instrumentar código nuevo.
